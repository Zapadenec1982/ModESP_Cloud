Пов'язані факти з коду, які документи мають відображати:

- Персональні дані, що зберігаються: email, хеш пароля, Telegram ID, координати домашньої бази техніка (`users.base_latitude/longitude`), адреси торгових точок, email/IP/user-agent у незмінному `audit_log`.
- Субпроцесори хостингового сервісу: Hetzner (VPS, Німеччина/Фінляндія), Telegram (бот), Google Firebase (FCM), Resend (email), провайдери карт і геокодування згідно з `docs/THIRD_PARTY_LICENSING.md`.
- Строки зберігання: телеметрія за планом (`plan_limits.retention_days`), погодинний архів 3 роки, аудит-лог без обмеження до впровадження псевдонімізації (план, епік 2.10).
